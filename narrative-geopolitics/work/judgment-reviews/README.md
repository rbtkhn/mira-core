# Judgment Reviews

This internal surface records later accountability reviews of daily
`judgment.md` packets. It does not replace the forecast ledger or reality
verification lattice.

Each review should record:

- the reviewed judgment date and review date;
- what changed in the world or evidence;
- which judgment strengthened, weakened, or remained unresolved;
- forecast outcome: supported, mixed, missed, or not yet resolved;
- what the voice/source set got right or wrong;
- one method lesson for the next judgment packet.

Use one dated review file per review cycle. Do not rewrite the original daily
judgment; append later accountability here.
