# Pilot Crisis Objects

Status: `internal-work`

This folder holds bounded pilot crisis objects before they qualify for public
watch promotion or active-dossier treatment.

A pilot object is structured memory, not verified truth. It records archive
source lanes, source-asserted mechanisms, open claims, historical frames, and
watch signals so later daily synthesis can test whether continuity changes
judgment.

Promotion to `public/watch.md` requires the existing watch promotion standard:
bounded object, explicit evidence posture, source-family limits, continuity
value, and at least one observable review condition.
