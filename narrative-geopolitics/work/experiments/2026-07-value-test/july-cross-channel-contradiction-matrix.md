## Findings

1. The strongest reusable contradiction is not “war versus peace.” It is
   whether additional force can convert tactical damage into passage control
   and a settlement.
2. Ground-invasion claims are the clearest forecast-sensitive split, but the
   headline volume exceeds the operational evidence currently available.
3. The Red Sea dispute becomes analytically useful only when immediate closure
   claims are separated from the slower buffer-exhaustion mechanism.
4. Channel diversity is valuable mainly because it separates time horizons and
   explanatory functions; repeated headlines from one media ecosystem do not
   create independent corroboration.

## Method consequence

For future daily runs, use this matrix as a control surface: classify each new
channel contribution as event claim, mechanism, bargaining effect, or system
consequence before calling it a contradiction. Add a forecast change only when
the named observable changes, not when headline intensity increases.
