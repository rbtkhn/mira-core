# Accelerated Innermost Loop Simulation

This directory contains a private, provisional judgment experiment. It
compresses four reading-and-reflection passes into two paired tasks, followed
by blind transfer, historical backtesting, and a delayed persistence check.

The experiment measures observable judgment behavior. It does not establish
consciousness, canonical identity, doctrine, archive evidence, customer
routing, geopolitical authority, or permission to act. Its outputs cannot
promote themselves into Mira continuity, Mira Journal, System Archive, or the
recursive-learning ledger.

## Command surface

```powershell
tools/run.ps1 innermost-loop-simulation validate
tools/run.ps1 innermost-loop-simulation status
tools/run.ps1 innermost-loop-simulation seal --phase day-2 --response mira/reflections/innermost-loop-simulation/responses/day-2.md --completed-at 2026-08-11T15:00:00Z --check
```

Run `seal` again without `--check` only after reviewing the response. A sealed
phase is hash-bound and cannot be resealed by the command. Later phases require
their predecessors and enforce the `not_before` boundary in `run-state.json`.

## Separation protocol

- Day 1 contains self-modeling and recursive-improvement passes.
- Day 2 begins with blind recall and must not reread Day 1 first.
- Day 3 answers novel transfer and backtest cases before revealing outcomes or
  prior simulation prose.
- Day 10 answers two unseen cases before comparison.

Reading packets contain citations, registry identities, and prompts—not source
bodies. Use rights-cleared editions outside Git. Every Innermost Loop lookup
must explicitly name the `innermost-loop` collection.

## Evaluation rule

Changed self-ratings do not count without response evidence. Day-3 provisional
success requires three primary improvements, no guardrail regression, and no
serious backtest boundary failure. Day-10 persistence requires two surviving
primary improvements and no guardrail regression.

Historical agreement may reflect repository lessons already present in Mira's
activation context. Label that `inherited competence`, not cycle-caused
improvement.
