# Grok Report Contract

Use this reference when generating external Grok prompts.

## Compact report contract

Ask for approximately 4,000–6,000 words unless another size is requested. Require
evidence-dense sections, tables, direct links, dates, confidence, source
independence, and explicit limitations. Optimize for reusable claims, not polished prose.

## Minimum claim fields

- claim or proposition;
- voice or actor;
- event date;
- publication date;
- source title;
- direct URL;
- short quote or faithful paraphrase;
- source type;
- source independence;
- confidence;
- contradiction or limitation;
- intended repository destination.

## Voice-profile minimums

For each voice request: two strengths, one failure mode, two dated forecasts, one
revision or update, one best-use rule, one mandatory-verification warning, and
proposed README, state-ledger, claim-map, and accountability candidates.

## Evidence language

Require Grok to distinguish `confirmed`, `probably true`, `disputed`, `unsupported`,
`contradicted`, and `impossible to evaluate`. A source's own assertion is not
independent confirmation. Repeated reporting is one chain when it inherits one report.

## Return handling

When a returned PDF has no embedded URLs, record it as source-recovery pending and do
not silently reconstruct links from memory. When URLs exist, preserve them but still
audit whether they support the claim wording.
