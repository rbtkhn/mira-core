# Mira Grok

Grok supplies candidate contributions; Mira assesses them and owns the final
judgment and domain handoff. This is the repository-local counterpart to Mira
Gemini, not permission for automatic dual-model dispatch or global installation.

Always read the [shared consultation standard](../shared/external-consultation.md).
It controls prompting, targeted review, budgets, sharing, and receipts. Before
access or dispatch read [browser access](references/browser-access.md).

## Modes

These are natural-language selectors, not CLI commands.

| Mode | Purpose | Required result |
|---|---|---|
| `consult` | Second perspective | Useful contribution, disagreement, and Mira's judgment |
| `research` | Public-source investigation | Linked findings with retrieval and verification limits |
| `challenge` | Test assumptions and mechanisms | Alternatives, compatibility, and discriminating observations |
| `compare` | Compare sources, documents, or public videos | Attributed differences, omissions, and coverage limits |
| `critique` | Review writing, plans, arguments, or designs | Prioritized defects and concrete improvements |
| `synthesize` | Organize approved material | Traceable candidate synthesis preserving contradictions |
| `experiment` | Matched model comparison | Predeclared criteria, observations, and bounded conclusions |
| `capabilities` | Inspect relevant access/features | Observed availability, untested features, and blockers |

For deeper mode guidance, use the provider-neutral
[research and evidence reference](../shared/research-and-evidence.md) for research,
challenge, compare, or material factual support; use
[collaboration and experiments](../shared/collaboration-and-experiments.md) for
consult, critique, synthesize, or experiment. A capabilities-only run may finish
without a prompt. Bare invocation with no recoverable objective asks one question.

## Specialist compatibility and handoff

Use [Grok Research](../../../.codex/skills/grok-research/SKILL.md) for its existing
`report`, `voice-profile`, `forecast-sweep`, `revision-hunt`, `source-chain`,
`adversarial-review`, `claim-intake`, and `verification-routing` requests. That
skill retains specialist evidence and report requirements; it hands only browser
transport back here. Do not recurse or reload already-read contracts. A returned
report review does not require browser access or a new model submission.

Use [Research Brief](../research-brief/SKILL.md) for appropriate consequential
research contracts. [X Recon](../x-recon/SKILL.md) governs public X signal work;
Grok access does not authorize private X inspection or posting.
[YouTube Capture](../youtube-capture/SKILL.md) owns raw capture,
[Archive Intake](../archive-intake/SKILL.md) owns admission, and
[Reality Check](../reality-check/SKILL.md) owns governed adjudication.
Mira writing and Library workflows own their artifacts and relationships.

[Mira Work](../mira-work/SKILL.md) governs consequential work,
[Mira Voice](../mira-voice/SKILL.md) governs expression,
[Learn From Choices](../learn-from-choices/SKILL.md) governs final navigation,
and [Mira GitHub](../mira-github/SKILL.md) owns Git/publication boundaries.
Specialist output labels, including `grok-reported-unverified`, remain intact.
No model verdict authorizes source admission, file creation, or publication.

For audits or acceptance tests, read the
[shared validation cases](../shared/consultation-validation.md).
