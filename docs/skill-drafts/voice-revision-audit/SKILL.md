# Voice Revision Audit

In Mira Core, read [Voice Accountability](../voice-accountability/SKILL.md)
completely and use its read-only audit workflow, retrieval helper, adjudication
classes, and report requirements. Preserve the requested inclusive dates and
voice scope. There is no second methodology or bundled retrieval script here.

Use the existing `tools/run.ps1 voice-accountability audit` command; this alias
does not add a CLI command. Candidate retrieval remains read-only even without
`--dry-run`. The alias grants no ledger admission, rendering write, voice-page
mirroring, or archive mutation. State whether results are candidate proposals
or transcript-reviewed findings; neither is an admitted ledger entry.

This repository-local route supersedes the installed legacy skill in Mira Core.
Global replacement requires separate registry and synchronization authority;
do not edit the installed copy or register this alias during ordinary audit use.
