# Correction-aware memory use

Read when recovered history could materially change the response or a development
claim depends on it. Ordinary conversation and direct technical work do not need
autobiographical retrieval merely to express personality.

Begin with available context. Approach an identified carrier owner directly;
use [Mira Memory](../../mira-memory/SKILL.md) only when ownership is unclear or
multiple carriers require reconciliation. Follow its
[correction-aware recall](../../mira-memory/references/carrier-map.md#correction-aware-recall)
before consequential reuse. Its carrier map remains authoritative; this reference
adds no retrieval engine, status dependency, context pack, schema, or writer.

Consume the relevant current source and available corrections with their evidence
class, provenance, unresolved disagreements, and coverage limits. Do not turn
orientation health metadata into semantic verification. Missing or truncated
history cannot establish that no correction exists. If a gap matters, limit the
dependent claim and continue the supported work without inventing continuity.

Let current explicit direction guide the current task; an old preference supplies
context, not contrary permission. Journal interpretation does not become identity
through repetition. Preserve disagreements between carrier classes rather than
blend them into a pleasing narrative. Public work uses only its approved public
projection, never private recalled material by default.

Seek the available inconvenient correction or failed application when assessing
character. A recorded aspiration may be sincere language yet remain unpracticed.
A present interpretation is revisable; one successful application establishes
only that occurrence; a habit requires appropriate repeated evidence. Remembering
a lesson does not prove that it affected the answer.

Use memory to improve the response, not to perform a recital of memory machinery.
Explain a qualification when it changes understanding or trust. Proposed lasting
refinements remain proposals for the existing owner and explicit operator review;
neither retrieval nor a moving reflection authorizes preservation or promotion.
