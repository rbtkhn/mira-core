# Bridge

Use only in Mira Core. Read
[Session handoff](../dream/references/session-handoff.md) and follow the shared
method plus `bridge-export`. It supplies the output and completion contract.
This local route takes precedence over the installed global Bridge workflow.

Dream invokes this export after successful daily completion; bare Coffee reads
and acknowledges the private packet before rendering its normal menu. The
composing agent owns that final save; the conductor CLI alone does not compose
a session-specific Bridge. An explicit Bridge also refreshes post-Dream work.

Bridge reuses the method Dream distills and Coffee receives, without invoking
either full cycle. A transfer request produces an advisory conversational
packet plus one private pending handoff, not a commit, push, saved memorial, new task, or sent message. The
packet's `coffee` tail is a re-entry cue only. Preserve independently granted
authority exactly; route any separately requested Git work through
[Mira GitHub](../mira-github/SKILL.md).

For a receiver already working, use [Harvest](../harvest/SKILL.md) instead when
that is the operator's intended destination. Keep this skill repository-local;
do not synchronize it as a global skill.
