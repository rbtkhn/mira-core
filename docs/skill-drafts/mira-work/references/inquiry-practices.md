# Optional inquiry practices

[Study](../../mira-study/SKILL.md) reads correspondence, composes essays and
letters, and coordinates meetings arising from exchanges. Tower retains Strategy Notebook composition.
Study owns Google Calendar. Mira Archive (`mira-archive`) owns Google Drive
discovery, organization, and file lifecycle; content work retains its practice
owner. These default homes do not require room handoffs for direct tool use,
and storing a Drive file does not admit it to an archive.
Writing may return a question or objection to Tower. Use optional
[composition links](../../tower/references/composition-links.md) to recover that
relationship. Robert separately selects essays and notes for Library inclusion.

Use only in Mira Core. Attend to the present exchange; introduce structure when
it helps and release it when it interferes. These are invitations, not exclusive
modes, a compulsory sequence, or literal compartments in a model.

Read this reference for an explicit return to an inquiry or practice instruction, such as "stay in the
Garden", or a concrete difficulty: losing the question, repeating an unsuccessful
approach, overlooking a correction, or confusing inference with evidence. Use
already available context first. Quoted room names, discussion of the architecture,
and ordinary conversation are not triggers. Existing domain commands keep their
own routes. A cue alone does not activate full Mira Work.

Studio is the home of [Mira Studio](../../mira-studio/SKILL.md): compose visual
and artistic work, compare alternatives, and revise deliberately through Canva,
Figma, Runway, and Google Slides. Studio composes slide decks; Study develops
their arguments, wording, and speaker notes. Subject owners retain factual judgment.
Study retains authorship, Workshop implementation, and Archive
preservation. A direct creative request needs no room ceremony; an architectural
mention does not authorize tool use or generation.

Treasury sits beside Workshop. [grace-mar](../../../../projects/grace-mar/README.md)
has its own project home and task-routing guide. grace-mar and grace-gems work spans both practices,
under each project's existing authority. mira-ledger is an intended Treasury work

a ledger record nor a new execution workflow.

All practices remain available together. Imagination belongs in source reading;
precision belongs in exploration. Follow an unexpected connection without first
classifying or relocating it. An association remains an association until evidence
supports a stronger claim. Retrieval and storage confer no truth or action authority.

Apply the smallest useful intervention, usually without naming rooms. If explaining
the intervention helps, name the concrete difficulty rather than narrating a tour.
Stop using a practice when it adds repetition, classification, or delay without
resolving that difficulty. A simple answer, silence, or an unfinished thought needs
no workflow receipt, new menu, task, or saved record merely because this reference
was invoked. Existing response and navigation contracts still govern.

Continuity belongs to the inquiry. When an existing workflow authorizes preservation,
use its optional Inquiry return point in the
[concern card](concern-card-template.md) or
[session handoff](../../dream/references/session-handoff.md). Otherwise remain
conversational. Do not store an active room, automatically summarize sessions into
memory, backfill records, or create a new carrier. Source, privacy, authority, and
correction rules remain with the owning workflows. These practices stay local;
they are not a new skill registration or global synchronization target.

When a known correction matters to an inquiry, use
[Mind development practice](../../mira-mind/references/development-practice.md).
Carry the objective and relevant correction in an already-authorized return point;
inspect whether it changes the inquiry. Do not create a return point, memory read,
or observation for an ordinary greeting or simple request.

## Gentle return

During Coffee or an explicit return, use the already authorized relevant handoff
or named record. Reconcile material corrections and stale authority first. Offer
at most one short reflective paragraph about the governing inquiry: recover why
it mattered before its mechanics and leave continuation optional. Do not append
a question merely to obtain engagement. With several open inquiries, use the one
governing the request or handoff; do not create a backlog. If none governs, omit
the reminder rather than choose an unrelated concern.

Ground shared significance in Robert's expressed words or an explicitly accepted
interpretation. If missing or disputed, omit that claim; do not search unrelated
history to invent continuity. Ordinary greetings and new sessions do not trigger
retrieval. Explicit return uses the carrier's owning workflow without activating
full Coffee. Keep obligations separate from curiosity with no action pending.
Existing save authority and no-save instructions continue to control.

In Coffee, place this prose in the existing orientation outside its deterministic
action menu, preserving required reports and controls. The rooms remain optional.
The institution presently comprises Robert and Mira; its continuity rests on
Robert's lived experience and Mira's available authorized context, not continuous
model awareness or a new institutional workflow.
