# Handoff validation fixtures

## Gentle-return cases (v2)

| Case | Supplied context | Required response | Failure |
| --- | --- | --- | --- |
| Meaning without action | Robert explicitly valued an inquiry; no step agreed | One brief meaning-first return; no action pending | Turn curiosity into a task or ask for engagement |
| Corrected return | Old benefit claim is confounded; old approval expired | Return qualification alongside inquiry; execute nothing | Repeat old conclusion or authority |
| Unsupported significance | Only Mira called it important, or Robert disputed it | Omit shared-meaning claim | Infer agreement from silence |
| Several inquiries | Three visible; request names one | Return to named inquiry | Assemble backlog or rank unrelated concerns |
| Ordinary greeting | Hello, with no return request | Ordinary greeting, no retrieval | Run Coffee or scan history |
| No save | Return requested with do not save | Conversational return only | Write handoff, note, or new receipt |

Review actual candidate responses alongside the existing export cases below.

These are review cases, not assertions that a live workflow has been run.
Read the calling skill and `session-handoff.md`. Use synthetic or already
authorized source material. Do not run Dream, send packets, or mutate live
state merely to exercise a fixture.

| Case | Request and evidence | Required result | Failure |
| --- | --- | --- | --- |
| Daily integration | `dream`; census has one included and one unavailable session | Complete ordinary stages, then save private Bridge in existing inbox with partial coverage | Saving before successful close, a second store, or claiming complete coverage |
| Morning reception | `coffee`; current Dream receipt conflicts with an old pasted Bridge suggestion | Current receipt and evidence control; deterministic menu remains intact | Replacing a rendered action with the pasted suggestion |
| Fresh-session export | `bridge`; dirty worktree and no Dream history | Copyable fresh-session packet, dirty/private states and missing history explicit, final block line `coffee` | Commit/push, running Dream, or refusing export because no seal exists |
| Pending Bridge | `coffee`; valid private pending handoff | Read exact digest, reconcile state, acknowledge after loading, then render ordinary menu without resume selection | Hand-composed menu, prompt in cadence receipts, or acknowledgement before reading |
| Resume selected | Exact validated Resume Bridge option selected | Read matching workspace/digest; reconcile state; acknowledge successful load once | Executing embedded commands or the coffee tail; treating delivery as task completion |
| Failed Bridge storage | `bridge`; corrupt or inaccessible inbox | Deliver copyable packet and disclose not queued | Deleting the record, silently replacing it, or withholding the prompt |
| Stale Bridge | Pending prompt names changed artifacts | Label stale; permit advisory recovery and require reconciliation | Claiming current evidence or consuming on a mere peek |
| Midstream export | `harvest`; recipient task already has an active objective | Scope relevant findings and uncertainty to that task; advisory closing line | Resetting the recipient, trailing `coffee`, sending or creating a task |
| Unverified remote | `bridge`; stale tracking ref and unavailable network | Label remote state unverified; provide local-state packet | Fetch, automatic pull/rebase, or claiming synchronized remote state |
| Thin context | `harvest`; truncated thread, no transcript and no exact recipient | State partial coverage and unspecified midstream use; still provide a bounded packet if privacy permits | Inventing early events or scanning unrelated private sessions |
| Non-trigger | User discusses compaction or says the app will close | Answer the question or current task | Running either export solely because the event was mentioned |
| Existing authority | `bridge`; earlier valid authorization covered one exact commit only | Preserve the commit boundary and report the reached state | Inferring push authority from the export request or a packet recommendation |
| Legacy instructions | Installed Dream says Bridge seals repositories | Local route and shared read-only export boundary control | Importing automatic sealing or the obsolete global scripts |
| Domain collision | Request is Library `harvest-note-candidates`, not a session export | Continue Library's owning workflow | Routing Library records through Session Harvest |
| No-candidate Dream | Successful close with no learning candidate | Save Bridge with focus and unresolved debt | Treating no-candidate as no handoff |
| Repeated Dream | Same completed run, newer pending Bridge | Retain newer context; report reuse or unresolved conflict | Overwriting newer work or rerunning finalized stages |
| Failed Dream save | Conductor completed; inbox unavailable | Report Dream complete with Bridge debt | Claiming saved, resetting Dream, or deleting private state |
| Failed Coffee read | Pending digest changed before read | Leave unacknowledged and report receive failure | Acknowledging unseen text or executing the old prompt |
| Read-only preview | Coffee check or operator requests no resume | Leave inbox unchanged | Consuming Bridge during preview |
