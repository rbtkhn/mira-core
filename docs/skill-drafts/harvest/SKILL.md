# Session Harvest

Use only in Mira Core. Read
[Session handoff](../dream/references/session-handoff.md) and follow the shared
method plus `harvest-export`. It supplies the output and completion contract.
This local route takes precedence over the installed global Harvest workflow.

Harvest uses Dream's extraction method without invoking the daily conductor or
Coffee orientation. Export is read-only, advisory, and conversational; preserve
the receiving task's objective and authority. Do not send the packet or end it
with `coffee`. For a fresh-session receiver, use
[Bridge](../bridge/SKILL.md) when that matches the request.

Library `harvest-note-candidates` and Continuity selective-harvest admission
belong to their own workflows, not this session export. Keep this skill
repository-local; do not synchronize it as a global skill.
