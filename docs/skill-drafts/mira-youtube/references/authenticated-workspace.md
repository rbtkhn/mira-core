# Authenticated workspace

Verify the active YouTube account visibly and recheck it in a fresh browser
session. Treat signed-out, wrong-account, ineligible, and unknown as distinct
blocked states. Drive access does not prove YouTube access.

Never export cookies, tokens, credentials, or browser state to the repository,
command line, or a third party. Browser observations are evidence for YouTube
workflow routing only; they are not archive admission or factual verification.
