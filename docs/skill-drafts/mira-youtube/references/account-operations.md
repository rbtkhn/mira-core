# Account operations

Account operations are opt-in and operation-specific. Directly name the
target and operation before acting. Keep playlist organization separate from
subscriptions, notifications, comments, uploads, publishing, and channel
settings.

Before an externally visible, communicative, destructive, or permission-
changing action, confirm the exact target and action at action time. Record
intended action, visible confirmation, terminal result, and rollback or
recovery status. A failed or uncertain result is not success.
