# Tower compatibility

Tower is retired as a room. Mira Mind supplies strategic cognition in every room
and owns [Strategy Notebook](../mira-mind/references/strategy-notebook.md).
An old Tower invitation recovers advisory inquiry context; it does not silently
open a named Notebook inquiry or authorize saving, acquisition, or publication.
Explicitly starting or resuming named Notebook work uses Mind's close boundary.
Explicit current or pending geopolitical work follows
[Geo-Strategy acquisition](../geo-strategy/references/acquisition.md).

The `tower` CLI remains a compatibility adapter: context and close delegate to
Strategy Notebook; pending, activate and survey-plan delegate to Geo-Strategy.
Legacy replay retains its exact request digest. New canonical contributions
require inquiry_id. No private store migration or new activation is implied.
