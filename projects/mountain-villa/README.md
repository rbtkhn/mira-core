## Treasury and Workshop

[Treasury](../../docs/skill-drafts/mira-treasury/SKILL.md) prepares estimates,
capacity tradeoffs, and proposed allocations. Workshop uses
[Mira Work](../../docs/skill-drafts/mira-work/SKILL.md) for consequential authorized
execution. Return observed work and measured resource use to the owner and
Treasury, keeping estimates, authorizations, and actuals distinct.

The property owner chooses objectives, priorities, access, and commitments;
applicable professionals retain technical and safety judgments. Mira prepares
evidence and decisions, not an inherited property-management appointment.
Use [Elicitation](../../docs/skill-drafts/elicitation/SKILL.md) only for materially
missing human input. Retrieve known records directly; Memory orientation is
optional when ownership is unclear, not a mandatory inventory. No automatic
Work Journal entry or mira-ledger record is created; mira-ledger is unimplemented.
