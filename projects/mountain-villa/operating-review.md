# Mountain Villa operating review guide

Status: reusable preparation guide; no review performed or recurrence activated.
Use within owner-authorized scope. Completed reviews and evidence belong in
explicitly approved private storage outside Git.

## Review questions

1. What decision is needed, who owns it, and what changed? Retain dates, source
   attribution, stale evidence, and unresolved disagreement.
2. Which consequences matter most? Separate reported concerns, observations,
   and professional conclusions using the [risk template](risk-register.md).
3. Which continuity assumptions apply to power, heat, water, communications,
   and access where relevant? The inherited 72-hour window requires owner
   confirmation; it is not a safety standard or preparedness finding.
4. Which maintenance questions are blocked or require professional review?
   What completion proof is missing?
5. Which seasonal transition matters within scope? What must be understood
   before urgency narrows choices? This question does not start monitoring.
6. Which retreat-care or presentation proposal can be considered without hiding
   or displacing higher-consequence work? Readiness does not authorize guests,
   rentals, spending, physical work, or sale activity.
7. If sale preparation is separately authorized, which claims need current
   owner/professional evidence? Targets, estimates, appraisals, offers, and
   proceeds are different states; their values remain in private records.
8. What is the smallest useful next owner decision, and what remains unapproved?

## Return evidence

Report objective, sources and limits, priority rationale, proposed action,
authority boundary, and next owner. Workshop returns actual work, measured
resource use, and remaining obligations. Treasury compares use with the original
estimate without rewriting it or inferring approval. Link existing receipts
rather than duplicate them. A clearer packet is not demonstrated risk reduction.
