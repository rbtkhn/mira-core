# Geo-Strategy Validation Series

Purpose: test whether `geo-strategy` increases the value extracted from each
landed source batch, not merely whether its prose improves.

## Project Value Thesis

The series targets faster archive-to-judgment movement, better reuse of source
and dossier state, fewer duplicated or unsupported claims, more useful
forecasts, stronger cross-day continuity, lower validation rework, and better
decision relevance without expanding authority.

## Experiment Order

1. Baseline-to-Judgment Throughput
2. OPC and Forecast Risk Reduction
3. Three-Day Dossier Continuity
4. Dense-Day Mechanism and Voice Leverage
5. Thin-Day Compression

Each experiment must use the [scorecard](scorecard.md) and produce a packet
from [the template](experiment-packet-template.md). Do not copy archive bodies;
link to manifest-backed sources and generated outputs.

## ROI Rules

- Promote only when project value improves without an authority or evidence failure.
- Revise when insight improves but production cost or rework rises.
- Defer when skill quality improves without project payoff.
- Reject unsupported claims, authority drift, or low-value complexity.
- Stop after two consecutive experiments without measurable project improvement,
  or when refinement costs more than the rework it removes.

## Release Gates

- Project throughput improves or manual repair declines.
- Each retained synthesis has a mechanism, contradiction, forecast, or decision
  implication that justifies its existence.
- A multi-day run produces reusable dossier or forecast value.
- OPC, forecast, publication, and verification boundaries remain intact.
- Maintenance burden remains proportionate to project value.
- Repository, mirror, compatibility alias, scripts, and tests remain aligned.
