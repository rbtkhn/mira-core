# Mira Session Memorials

This shelf holds curated, Mira-reflective memorials of one canonical Continuity
session each. Every admitted version is a matching Markdown and JSON pair
registered in [`registry.json`](registry.json). Raw conversation remains in
Continuity captures and is referenced, never copied here.

Retrieval is explicit-only and every memorial remains inactive. Preservation is
not evidence of consciousness, present identity, truth, operator belief, or
permission. Missing memorials are not evidence that a session lacked value.

`tools/run.ps1 mira-sessions validate` checks the admitted shelf. Admission and
private Mira Archive ingestion are separate operations. Staging, commit, push,
publication, ingestion, and activation each require their own authority.
