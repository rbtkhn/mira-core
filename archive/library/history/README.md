# History

History preserves the Library's existing era shelves and source authorities.
Their existing paths and historical seals remain valid; this section is the
navigation entry point, without relocating source records or private bodies.

- [Ancient](../ancient/index.md)
- [Medieval](../medieval/index.md)
- [Colonial / early modern](../colonial/index.md)
- [Industrial](../industrial/index.md)
- [Digital](../digital/index.md)

The shared [registry](../library-registry.json) remains authoritative. Existing
records without a `section` field belong to History. New Science records use
`section: science` and publication dates instead of eras.
