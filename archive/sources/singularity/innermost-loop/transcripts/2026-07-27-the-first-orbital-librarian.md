# The First Orbital Librarian

Source: The Innermost Loop with Dr. Alex Wissner-Gross
URL: https://theinnermostloop.substack.com/p/the-first-orbital-librarian
Date published: 2026-07-27

## Source body digest

The feature introduces Hermes, an open-source agent framework from Nous Research, as planned for an early-next-year StarVault launch. It distinguishes this proposed “orbital librarian” from prior orbital AI examples by assigning it a continuous custodial role: organizing collections, maintaining semantic indexes, resolving conflicts, enriching metadata, and preparing retrieval context for a customer-selected sovereign model.

The article connects the concept to Lonestar's orbital data embassy and sovereign model ideas. It emphasizes isolated trust domains, owner keys and access policies, no shared customer memory or inference state, and the analogy between orbital storage and a library's long-term curation labor.

The feature also acknowledges earlier orbital AI systems, including NASA's Remote Agent, EO-1, CIMON, and an orbiting H100, while claiming the librarian role is distinct. The operational claim remains prospective: launch timing, architecture, ownership model, and reliability require independent verification.
